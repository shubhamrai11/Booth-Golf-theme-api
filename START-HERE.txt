FAIRWAY STUDIO — TEMPORARY PHOTO BUILD 0.4.0

CYCLE
Capture -> Review -> Generate -> Print -> Clear.
One guest photo lives in browser memory. Refresh/delete/retake clears it.
A successful Windows print submission clears the result and returns to welcome.
No guest photo files, database, photo history or QR download links are created.

START
Extract the entire package. Keep runtime, native, public and dist folders together.
Double-click Fairway Memory Helper.exe for the hosted booth (port 4314).
For a fully local booth, double-click Fairway Studio.exe (port 4310).
Keep the helper running throughout the event. Closing a browser does not stop it.

SETUP
Open Settings on the welcome screen. On the Windows helper, configure:
- licensed 64-bit Canon EDSDK folder (SDK is not included)
- Windows photo printer and its 4 x 6 portrait paper settings
- your OpenAI API key, saved with Windows user encryption
- generation mode, model, prompt and print frame

API KEY FILE
Copy .env.example to .env beside the helper EXE (or in the source-code root).
Paste your key after OPENAI_API_KEY=, save, and restart the helper/app.
The only required value is OPENAI_API_KEY. Keep .env private.
A nonempty api-key.local.mjs or process environment key takes priority over
.env; .env takes priority over the encrypted key saved in Settings.

Canon R100 / EOS 200D needs USB, JPEG mode and compatible licensed EDSDK.
Close EOS Utility. Canon live video is not implemented; the capture appears
following the six-second countdown. Browser webcam capture is also available.
Folder watching is removed because it requires photo files on disk.
Physical camera and printer operation still require an event-hardware test.

VERCEL
Follow VERCEL-SETUP.md. In your Vercel project, go to Settings -> Environment
Variables -> Import .env, select your private file, choose Production, and Save.
Redeploy after saving. You can also enter OPENAI_API_KEY and its value manually.
Never upload .env to GitHub or include it in public website files.
Use the same key in Windows helper Setup. No Supabase/password/manual token.
On the same Windows PC, open the hosted /kiosk page. In Settings, choose Connect
Windows helper, allow the browser's local network request if asked, then verify
the website address and select Allow connection in the helper window.
The connection lasts 12 hours or until the helper restarts. Reconnect after restart.

REFERENCES
Choose your event reference, optional outfit image and transparent PNG branding
in website Settings. They stay in browser memory while moving back to welcome,
but a full refresh removes them. The bundled scene is an illustrative fallback.
Only the captured guest image supplies identity. References guide scene/clothing.
No guest photo upload option is displayed. Check likeness before printing.

AI
Rehearsal is the default: no charge and no golf transformation.
Live defaults: Sunburst / Max / 1536 x 2304. Final print: 1200 x 1800 JPEG.
Vercel free-plan generation must finish in 300 seconds; AI is limited to 240.
Use High quality or run locally if Max consistently takes too long.
No automatic retry is made. A timeout or refresh may still be charged by the
provider. Refresh loses the photo/result and cannot recover the previous request.

PRINT AND DISPLAY
The Windows bridge reads pixels from memory and sends one copy to the spooler.
The app clears when Windows accepts the job; this does not confirm paper output.
Windows may keep spool data according to its printer settings.
With hosted browser Rehearsal and no helper, printing uses the browser dialog.
After printing, choose Done & clear photo. If canceled, the photo remains available.
Open /display in another window of the same browser profile and website origin.
Move it to the large screen and choose Full screen. Only the current portrait is
shown. It clears with the guest page, or within ten seconds after disconnection.

PRIVACY
Only equipment settings, encrypted credentials and command IDs persist locally.
These contain no guest images. Website preferences contain text/settings only.
The AI provider's retention rules remain separate. Older versions' data folders
are not migrated or deleted. Use this new build for the temporary photo cycle.
Never publish API keys, private key modules, settings, old data or Canon SDK files.
